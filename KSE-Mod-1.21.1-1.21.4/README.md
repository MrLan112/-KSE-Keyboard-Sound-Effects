# [KSE] Keyboard Sound Effects 1.21.1 - 1.21.4

Minecraft 1.21.1 - 1.21.4 (Fabric). Needs Java 21.

Build: `./gradlew build` (Windows: `gradlew.bat build`).
The mod is `build/libs/kse-keyboard-sound-effects-1.0.1.jar`; ignore the `-sources.jar`.

Built-in sounds: `src/main/resources/assets/kse/sounds/`.
Settings key: **B** (changeable in Options > Controls) or Mod Menu.
