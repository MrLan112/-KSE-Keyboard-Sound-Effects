# Changelog

## 1.0.1

- Mod Menu support: open the settings with the config button
- Volume slider
- The sound list is a real scrolling list (mouse wheel or scrollbar)
- Preview button next to "Select" on every sound
- New sounds: "Creamy Keyboard" and "Rizz Sound Effect" (first and second in the list)
- "Play only when a specific key is pressed" option and a key editor
- No sound by default: the player chooses one first
- Sounds are played on a separate thread
- One project now covers several Minecraft versions
- Added Minecraft 26.1, 26.2 and 26.3
